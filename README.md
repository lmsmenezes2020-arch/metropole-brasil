# Metrópole — Brasil Milionário

Jogo imobiliário independente para 2 a 6 jogadores, em português brasileiro, com valores fictícios em reais e R$ 25 milhões iniciais por participante.

## Publicação completa

Este repositório receberá a página e o servidor de salas da versão 4.0. Enviar apenas o HTML não instala as salas online.

Projeto existente no Netlify: `celadon-biscotti-4a8f9d`.

As salas usam HTTPS e armazenamento no servidor; o navegador do anfitrião não funciona como servidor. As regras incluem terrenos brasileiros, construção sem completar cores, hotéis, companhias, trocas, empréstimos, garantias, chat e retorno à partida.

## Privacidade

O código de sala é privado. Recuperação por código e nome não é autenticação forte. Não compartilhe informações pessoais pelo chat. Todo dinheiro no jogo é fictício; não há apostas nem pagamentos reais.

## Estado da implantação

Repositório inicializado para receber o projeto completo. A publicação no Netlify e o teste do endpoint `/api/metro/info` devem ser confirmados antes de apresentar o site como funcional.
